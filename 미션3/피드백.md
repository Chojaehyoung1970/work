# 미션 3 피드백 (To. 민수 님)

민수 님, 미션 3 영화 티어리스트 앱을 정말 잘 만들어 주셨어요! 전체적으로 꼼꼼하게 고민하신 흔적이 돋보입니다. 

## 🌟 잘된 점: 직접 써 보니 좋았던 것
- 등급마다 색깔이 달라서 S등급 칸이 한눈에 들어오는 점이 아주 직관적이고 좋았습니다.
- 상단에 ‘8편 중 3편 나눔’처럼 진행 상황을 알려주는 텍스트가 있어서, 분류가 얼마나 남았는지 쉽게 파악할 수 있었어요.
- 카드를 끌어다 놓을 때 칸의 색이 살짝 변해서 어디에 놓일지 시각적으로 알려주는 디테일이 훌륭합니다!

## 🛠 고치면 좋을 점

**첫번째**
- **본 것:** 브라우저를 새로고침하거나 창을 닫았다가 다시 열었더니, 분류해 두었던 영화들이 모두 처음의 미분류 상태로 돌아갔습니다.
- **기준:** 기획서의 "같은 파일을 다시 열어도 영화와 등급이 남습니다." 조건
- **제안:** `localStorage`를 활용하여 카드를 옮길 때마다 현재 상태를 저장하고, 페이지를 처음 열 때 그 데이터를 불러오도록 바뀌면 좋겠습니다.

**두번째**
- **본 것:** 새로운 영화를 직접 추가한 뒤 '처음으로' 버튼을 눌렀더니, 기본 영화 8개는 미분류로 돌아갔지만 새로 추가한 영화는 화면에 지워지지 않고 그대로 남아있었습니다.
- **기준:** 기획서의 "처음 영화 목록과 배치로 돌아갑니다." 조건
- **제안:** '처음으로' 버튼을 누르면 새로 추가된 데이터도 완전히 삭제되고, 딱 처음 상태의 8개 영화만 남도록 초기화 로직이 바뀌면 좋겠습니다.

**세번째**
- **본 것:** 영화 제목 입력창을 비워둔 채로 '추가' 버튼을 눌렀더니, 글자가 없는 빈 카드가 생성되었습니다.
- **기준:** 기획서의 정상적인 데이터 입력 의도 (기획서에 명시되진 않았으나 화면을 망칠 수 있는 버그)
- **제안:** '추가' 버튼을 눌렀을 때 입력창이 비어있는지 확인하는 조건문을 넣어서, 빈칸일 경우 경고창(alert)을 띄우고 카드가 만들어지지 않게 막아주면 좋겠습니다.

**네번째**
- **본 것:** 미분류된 영화를 맨 위의 S칸으로 끌어다 놓으려고 했더니, 화면 스크롤을 같이 위로 올려야 해서 드래그하기가 번거로웠습니다.
- **기준:** 쓰다가 불편했던 점 (사용자 경험)
- **제안:** 미분류 영화 목록을 화면 맨 아래가 아니라 상단이나 우측 등 드래그 동선이 짧은 곳으로 옮기면 훨씬 편하게 영화를 분류할 수 있을 것 같습니다.
