# 학습 자료 링크 정리 페이지

## 대상 사용자

- 흩어진 학습 자료 링크를 한곳에 모아 두고 싶은 개인 사용자(나 혼자 사용)
- PC와 모바일 모두에서 열어 보는 사용자 (반응형 화면)

## 사용 목적

- **(가장 중요) 모아 둔 학습 자료 링크를 보기 좋게 정리해서 한눈에 확인하고, 새 링크를 쉽게 추가한다.**
- 링크를 카테고리와 태그로 분류해 원하는 자료를 빠르게 찾는다.
- 저장한 링크가 브라우저를 닫았다 열어도 그대로 남아 있게 한다.

## 화면 구성과 동작

- **상단 바**: 페이지 제목, 보기 전환 버튼(표 ↔ 카드), 정렬 선택, 다크 모드 버튼, "링크 추가" 버튼이 있습니다.
- **링크 목록(중앙)**: 저장된 링크들을 보기 좋게 보여 주는 영역입니다. 표 또는 카드 형태로 전환됩니다.
- **링크 입력 폼**: "링크 추가"나 "수정"을 누르면 나타나며, 제목·URL·카테고리·설명·태그·아이콘(썸네일)을 입력합니다.

동작:
- "링크 추가" 버튼을 누르면 입력 폼이 열리고, 저장하면 목록에 새 링크가 바로 나타납니다.
- 각 링크의 "수정"을 누르면 기존 내용이 폼에 채워지고, 고쳐서 저장하면 목록이 갱신됩니다.
- 각 링크의 "삭제"를 누르면 확인 후 목록에서 사라집니다.
- "표 ↔ 카드" 버튼을 누르면 같은 자료가 다른 형태로 보기 좋게 다시 표시됩니다.
- 정렬을 선택하면 목록이 이름순 또는 최근 추가순으로 다시 정렬됩니다.
- 다크 모드 버튼을 누르면 화면 색상이 밝은/어두운 테마로 바뀝니다.

## 필요한 자료

- 링크 한 개당 정보: 제목, URL, 카테고리, 설명, 태그, 아이콘(썸네일)
- 기본 카테고리 목록(예: 강의, 문서, 블로그, 영상, 기타) + 사용자가 직접 추가 가능
- 처음 열었을 때 비어 있지 않도록 샘플 링크 5개

## 완료 기준

(페이지의 완료 여부를 판단할 조건)

- 링크를 추가하면 목록에 보기 좋게 바로 나타난다. (← 가장 핵심 목적)
- 저장된 링크들이 표/카드 형태로 정돈되어 한눈에 보인다. (← 가장 핵심 목적)
- 링크를 수정하면 바뀐 내용이 목록에 반영된다.
- 링크를 삭제하면 목록에서 사라진다.
- "표 ↔ 카드" 전환 버튼을 누르면 보기 형태가 바뀐다.
- 카테고리를 새로 추가하면 선택 목록에 나타난다.
- 정렬을 바꾸면 이름순/최근 추가순으로 다시 정렬된다.
- 다크 모드를 켜고 끌 수 있다.
- 브라우저를 닫았다 다시 열어도 저장한 링크가 그대로 남아 있다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열린다.

## 추가 기능

- 다크 모드(밝은/어두운 테마 전환)
- 정렬(이름순 / 최근 추가순)

## 한계 및 비목표

(기획 단계 초안 — 최종 HTML에 맞게 수정)

1. 데이터는 그 브라우저의 localStorage에만 저장되므로, 다른 기기나 다른 브라우저와는 공유되지 않는다.
2. 서버·회원가입·로그인 기능은 만들지 않는다(혼자 쓰는 로컬 페이지).
3. 링크 검색 기능, 데이터 백업/내보내기(가져오기) 기능은 이번 범위에서 제외한다.
4. 링크 URL이 실제로 살아 있는지(접속 가능 여부)는 확인하지 않는다.

## 검증 방법

(기획 단계 초안 — 최종 HTML에 맞게 수정)

- 링크를 추가한 뒤, 입력한 제목·URL이 목록에 그대로 보이는지 눈으로 대조한다.
- 표/카드 전환 버튼을 눌렀을 때 같은 링크가 두 형태 모두에 나타나는지 확인한다.
- 수정·삭제 후 목록 개수와 내용이 의도대로 바뀌었는지 확인한다.
- 정렬을 바꾼 뒤 순서가 기준(이름/최근)에 맞는지 손으로 비교한다.
- 링크를 저장하고 브라우저를 새로고침/재실행한 뒤에도 자료가 남아 있는지 확인한다.
