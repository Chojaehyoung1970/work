# 개인 학습 자료 링크 정리 웹페이지

## 대상 사용자

- 학습 자료 링크를 한곳에 모아 관리하려는 개인 사용자 (본인)
- PC와 모바일을 번갈아 사용하는 환경 (반응형 화면 지원)

## 사용 목적

- 흩어져 있는 학습 자료 링크(강의, 문서, 블로그 등)를 한 페이지에 모아 정리한다.
- 링크를 직접 추가·수정·삭제하고, 카테고리와 태그로 분류해 빠르게 찾는다.
- 브라우저에 저장해 두고, 다시 열었을 때도 내용이 그대로 유지되게 한다.

## 화면 구성과 동작

- **상단 바**: 페이지 제목, `+ 추가` 버튼, 보기 전환 버튼(표 ↔ 카드), 정렬 선택, 다크 모드 토글
- **목록 영역**: 저장된 링크를 표 또는 카드 형태로 표시
  - 각 항목에는 아이콘/썸네일, 제목, URL, 카테고리, 설명, 태그, 수정/삭제 버튼이 보인다.
- **추가/수정 폼**: `+ 추가` 또는 항목의 `수정`을 누르면 입력 폼이 열린다.
  - 제목, URL, 카테고리(선택 + 직접 추가), 설명, 태그, 아이콘/썸네일을 입력한다.
  - `저장`을 누르면 목록에 반영되고 브라우저에 저장된다.
- **동작 요약**
  - `+ 추가` 클릭 → 빈 폼이 열림 → 입력 후 저장 → 목록에 새 항목 추가
  - 항목의 `수정` 클릭 → 기존 값이 채워진 폼 → 수정 후 저장 → 해당 항목 갱신
  - 항목의 `삭제` 클릭 → 확인 후 목록에서 제거
  - `표/카드` 버튼 클릭 → 표시 형태 전환
  - `정렬` 선택 → 이름순 또는 최근 추가순으로 재정렬
  - `다크 모드` 토글 → 밝은/어두운 테마 전환

## 필요한 자료

- **링크 1건의 정보**: 제목, URL, 카테고리, 간단한 설명, 태그, 아이콘/썸네일
- **기본 카테고리 목록**: 미리 정해둔 몇 개(예: 개발, 디자인, 강의, 문서, 기타) + 사용자 추가 가능
- **샘플 링크 5개**: 처음 열었을 때 화면이 비어 보이지 않도록 예시 데이터 포함

## 완료 기준

(페이지의 완료 여부를 판단할 조건을 작성합니다)

- `+ 추가`로 링크를 입력해 저장하면, 목록에 새 항목이 바로 나타난다.
- 항목을 수정/삭제하면, 그 결과가 목록에 즉시 반영된다.
- 표 ↔ 카드 버튼을 누르면 같은 데이터가 두 형태로 번갈아 표시된다.
- 카테고리를 새로 추가하면 선택 목록에 반영되고, 해당 카테고리로 링크를 저장할 수 있다.
- 정렬을 바꾸면(이름순/최근순) 목록 순서가 그에 맞게 바뀐다.
- 다크 모드를 켜고 끄면 화면 테마가 바뀐다.
- 브라우저를 **새로고침해도** 추가·수정한 내용이 그대로 유지된다.
- 처음 열면 샘플 링크 5개가 보인다.
- **다른 파일이나 로그인 없이 HTML 파일 하나로 열린다.**
- PC와 모바일(좁은 화면)에서 모두 보기 좋게 표시된다.

## 추가 기능

- 🌙 다크 모드
- ↕️ 정렬 (이름순 / 최근 추가순)

## 한계 및 비목표

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

1. 데이터는 브라우저(localStorage)에만 저장되므로, **기기·브라우저마다 따로** 관리된다. (PC와 모바일 간 자동 동기화는 하지 않음)
2. 서버·로그인·회원 기능은 제공하지 않는다. (개인용 단일 페이지)
3. 검색, 태그/카테고리 필터, 데이터 내보내기/가져오기(백업)는 이번 범위에서 제외한다.
4. 아이콘/썸네일은 사용자가 입력한 값을 사용하며, 외부에서 자동으로 가져오지 않는다.

## 검증 방법

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

- **추가/수정/삭제**: 직접 조작한 결과가 화면 목록과 일치하는지 눈으로 확인한다.
- **저장 유지**: 링크를 추가한 뒤 새로고침하여 내용이 그대로 남아 있는지 확인한다.
- **보기 전환**: 표와 카드에서 같은 항목 수·같은 내용이 보이는지 대조한다.
- **정렬**: 이름순/최근순 선택 결과가 예상한 순서와 일치하는지 몇 개 항목으로 확인한다.
- **반응형**: 브라우저 창을 좁히거나 모바일에서 열어 레이아웃이 깨지지 않는지 확인한다.
- **단일 파일 실행**: HTML 파일을 더블클릭해 다른 파일 없이 정상 동작하는지 확인한다.
