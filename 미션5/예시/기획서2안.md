# 학습 용어 정리 웹페이지 기획서

## 대상 사용자

- 교육을 받고 있는 학습자 (PC·모바일 모두 사용)

## 사용 목적

- 학습용 용어를 보기 좋게 정리하고 쭉 훑어보기
- 용어명이나 뜻으로 원하는 용어를 빠르게 검색하기
- 공부하면서 새 용어를 직접 추가·수정·삭제하며 관리하기

## 화면 구성과 동작

- **헤더:** 페이지 제목 표시
- **검색창:** 용어명 또는 뜻을 입력하면 즉시 해당 용어만 걸러서 표시
- **카드/표 전환 버튼:** 누르면 카드 보기 ↔ 표(테이블) 보기로 전환
- **카테고리 탭(필터):** 특정 카테고리를 누르면 그 카테고리 용어만 표시 ('전체' 포함)
- **카테고리 추가 버튼:** 누르면 입력 폼이 열리고 카테고리명을 입력해 저장하면 카테고리 탭에 추가
- **용어 추가 버튼:** 누르면 입력 폼이 열리고, 용어명·뜻·카테고리를 입력해 저장하면 목록에 추가
- **용어 카드/행:** 용어명·뜻·카테고리를 표시하며, 각각 수정·삭제 버튼 제공
  - 수정 버튼 → 입력 폼에서 내용 변경 후 저장
  - 삭제 버튼 → 해당 용어 삭제

## 필요한 자료

- 용어 데이터 (항목: 용어명 / 뜻(설명) / 카테고리)
- 초기 샘플 데이터 3~5개

## 완료 기준

- 카드/표 전환 버튼을 누르면 두 가지 보기 방식이 서로 바뀐다
- 카테고리 탭을 누르면 해당 카테고리 용어만 표시된다
- 검색창에 입력하면 용어명·뜻에 해당 글자가 포함된 용어만 표시된다
- 용어를 추가·수정·삭제하면 화면에 즉시 반영된다
- 카테고리를 추가.수정.삭제하면 화면에 즉시 반영된다
- 추가·수정·삭제한 내용이 새로고침 후에도 유지된다 (localStorage)
- PC와 모바일 화면에서 모두 보기 좋게 표시된다 (반응형)
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열린다

## 추가 기능

- 용어 중요도 표시(별표), 예시 문장 항목 추가
- 데이터 내보내기/가져오기 (파일 백업)
- 다크 모드

## 한계 및 비목표

1. 데이터는 브라우저의 localStorage에만 저장되어, 다른 기기·다른 브라우저와는 공유되지 않는다
2. 로그인·회원가입 등 사용자별 계정 기능은 제공하지 않는다
3. 서버나 데이터베이스를 사용하지 않으므로 여러 사람이 동시에 함께 편집할 수 없다

## 검증 방법

- 샘플 용어를 추가한 뒤 새로고침하여, 입력한 내용이 그대로 남아있는지 확인한다
- 검색어를 입력했을 때 표시되는 용어가, 실제로 그 글자를 포함하는 용어와 일치하는지 눈으로 대조한다
- 특정 카테고리를 선택했을 때 표시되는 용어 개수가, 그 카테고리에 속한 용어 개수와 같은지 확인한다
- 카드 보기와 표 보기에서 같은 용어 내용이 동일하게 나오는지 비교한다
- PC와 모바일(또는 브라우저 창 크기 조절)에서 레이아웃이 깨지지 않는지 확인한다
