## 두 AI 비교
- AI A (서비스·모델 이름): 개인계정, 클로드Sonnet 5.5
- AI B (서비스·모델 이름): 코디세이 플랫폼, Gemini 3.1 PRO
- 동일한 기획서와 함께 전달한 요청: 기획서를 첨부하고 "이 기획서대로 HTML 파일 하나를 만들어 줘. CSS와 JavaScript까지 모두 이 파일 하나에 넣고, 다른 파일이나 로그인 없이 브라우저에서 바로 열리게 해 줘. 화면 문구는 한국어로 쓰고, 기획서에 없는 기능은 넣지 마"


| 테스트 내용 | AI A (Claude) | AI B (Gemini) |
| --- | --- | --- |
| 자료 추가 | 목록에 보기 좋게 나타남 | 좌동 |
| 자료 수정,삭제 | 바뀐 내용이 목록에 반영됨 | 좌동 |
| 새 카테고리 추가 | 선택목록이 나타남 | 좌동 |
| 표 ↔ 카드 전환, 정렬(최근/이름), 다크 모드 | 선택한 사항으로 변경됨 | 좌동 |
| 이름순 정렬 결과 | 정렬을 바꾸면 다시 정렬됨 | 좌동 |
| 새로고침 후 내용 유지 | 저장한 자료가 남아 있음 | 좌동|
| 자료를 전부 삭제한 뒤 새로고침 | 빈 목록 유지 | 샘플 5개가 다시 나타남 |
| 입력 폼 닫기 (Esc 키) | 닫힘 | 안 닫힘 (취소 버튼만 가능) |

- 선택한 결과물과 근거: A를 선택했습니다. 기획서의 완료 기준 항목은 두 파일이 모두 충족했습니다. 차이는 AI에게 테스트 요청 결과 두가지 사항에서 문제가 있었던 것으로 표시했고 개인적인 취향인 디자인도 A보다 B가 보기 좋았습니다.
