## 수정 기록

> 실제 수정 요청 내역이나 수정된 HTML 파일은 제공되지 않았습니다. 아래는
> 코드 검토에서 발견한 사항을 바탕으로 제안하는 수정 항목이며, 수정 완료
> 기록이 아닙니다.

### 수정 기록 1

-   발견한 문제: Gemini 파일은 localStorage.getItem 및 JSON.parse 과정에
    예외 처리가 없어 저장 데이터가 손상되었거나 브라우저 저장소 사용이
    제한된 경우 초기화 과정에서 오류가 발생할 수 있음. 저장 과정의 예외
    처리도 없음.
-   AI에게 전달한 요청: localStorage 데이터 읽기·파싱·저장 과정에
    try/catch를 적용하고, 데이터가 손상되었거나 저장이 불가능한 경우
    사용자에게 안내한 뒤 안전하게 기본 데이터를 표시하도록 보완해
    주세요.
-   수정 후 테스트 결과: 수정본이 제공되지 않아 확인하지 못함. 수정 후
    저장 데이터 손상, 저장소 접근 차단, 새로고침 상황을 테스트해야 함.
-   수정 이유: 예기치 않은 저장소 오류로 웹페이지 전체 기능이 중단되거나
    사용자가 변경 내용이 저장된 것으로 오해하는 상황을 줄이기 위해서임.

### 수정 기록 2

-   발견한 문제: Gemini 파일은 가져오기 JSON에 categories와 terms가
    있는지만 확인하고 항목별 자료형, 필수 속성, 카테고리 연결 관계를
    충분히 검증하지 않음. 확인 창 없이 현재 데이터를 덮어씀.
-   AI에게 전달한 요청: 가져오기 파일의 카테고리·용어 배열과 각 항목의
    필수 필드 및 카테고리 참조를 검증하고, 형식이 잘못된 파일은 적용하지
    않도록 해 주세요. 현재 데이터를 덮어쓰기 전 확인 창도 추가해 주세요.
-   수정 후 테스트 결과: 수정본이 제공되지 않아 확인하지 못함. 잘못된
    JSON, 필수 필드 누락, 존재하지 않는 카테고리를 참조하는 용어, 정상
    백업 파일 각각으로 테스트해야 함.
-   수정 이유: 잘못된 백업 파일로 기존 데이터가 손상되거나 의도하지 않게
    덮어써지는 것을 방지하기 위해서임.

### 수정 기록 3

-   발견한 문제: Gemini 파일은 카테고리 중복명 검사가 없고, 카테고리
    삭제 시 해당 용어의 categoryId를 빈 문자열로 바꿈. 화면에는
    '미분류'로 표시되지만, 용어 수정·추가 과정에서 카테고리 선택 상태와
    데이터 일관성을 확인할 필요가 있음. 또한 두 결과물 모두 인쇄 전용
    레이아웃은 확인되지 않음.
-   AI에게 전달한 요청: 카테고리 추가·수정 시 중복 이름을 검사하고,
    카테고리 삭제 후 미분류 용어를 일관되게 관리하도록 보완해 주세요.
    인쇄가 필요한 경우 화면 조작 버튼을 숨기고 용어 목록이 읽기 쉽게
    출력되는 인쇄 스타일도 추가해 주세요.
-   수정 후 테스트 결과: 수정본이 제공되지 않아 확인하지 못함. 중복
    이름, 카테고리 삭제 후 미분류 용어 표시·수정, 인쇄 미리보기로
    테스트해야 함.
-   수정 이유: 카테고리 데이터의 일관성과 사용 편의성을 높이고, 필요할
    때 학습 자료로 출력할 수 있도록 하기 위해서임.

## 종합 검토 의견

1.  두 결과물 모두 학습 용어를 카드 또는 표로 확인하고, 검색·카테고리
    필터·용어 관리·카테고리 관리·localStorage 저장·백업 기능을 제공하는
    단일 HTML 웹페이지 형태로 작성되어 있음.
2.  제공된 코드만 비교하면 Claude 결과물이 데이터 검증과 오류 대응
    측면에서 더 안정적인 구조를 갖추고 있어 우선 선택하는 것이 타당함.
3.  Claude 파일도 실제 브라우저에서 저장·복원, 화면 크기별 표시, 잘못된
    입력, 카테고리 삭제 제한 등을 실행 검증한 것은 아니므로 최종 배포 전
    테스트가 필요함.
4.  기획서에는 카테고리 추가·수정·삭제 후 화면 반영이 완료 기준으로
    제시되어 있고, Claude 파일은 현재 선택한 카테고리에 용어가 남아
    있으면 삭제를 차단하는 방식으로 처리함. 이는 데이터 유실을 막는
