# 미션 4 기록

- **사용한 AI 이름 / 주요 대화 캡처 파일명**: 제미나이3Flash/스크린샷4-1.png
- **더한 기능과 고른 이유**: 
  - **기능**: 영화 카드별 색상 변경 기능 (Color Picker 추가)
  - **이유**: 사용자가 등급별로 카드를 분류할 뿐만 아니라, 자신의 취향이나 영화의 분위기에 맞춰 카드의 색상을 직접 커스텀할 수 있게 하여 시각적인 만족도와 개인화 경험을 높이기 위해 추가했습니다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
| :--- | :--- | :--- |
| 영화_원본.html | 카드 색깔을 변경할 수 있어야 함 | **고치기**: 상단에 색상 선택기(input type="color")를 추가하고, 선택된 카드의 색상을 실시간으로 변경 및 저장하는 기능을 구현하여 완성함 |
| 영화_원본.html | 빈 제목은 추가하지 않음 | **완성**: 기존의 빈 제목 방지 로직이 유지되도록 코드를 검토하고 정상 작동 확인 |
| 영화_원본.html | '처음으로' 클릭 시 초기 상태 복원 | **고치기**: 초기화 시 추가된 영화와 변경된 색상 정보가 모두 초기값으로 돌아가도록 로직을 수정하여 완성 |

- **(선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유**: 
  - **내용**: 자바스크립트 객체 배열의 상태 관리와 로컬 스토리지 데이터 구조 설계
  - **이유**: 영화 제목, 등급 위치, 카드 색상 등 여러 데이터를 하나의 객체 배열로 묶어 관리하고, 이를 JSON 형태로 저장하고 불러오는 과정에서 데이터 정합성을 유지하는 가장 효율적인 방법이 궁금합니다.
